# Журнал змін PythonStart

## [1.0.0] - 2026-11-27

### Added

- Чотири теми Python з короткою теорією, кодом, вправою та підказкою українською.
- Каталог із пошуком за назвою й описом, фільтри прогресу та лічильник.
- REST-віджет із порадами й резервним текстом. Прогрес зберігається в браузері.
- Документація для учнів і вчителів, паспорт релізу та журнал CI.

### Changed

- Публікація вебтренажера на GitHub Pages. У підвалі доступні версія, інструкція та журнал змін.
- GitHub Actions запускає перевірку структури, синтаксису та модульні тести Vitest.

### Fixed

- [Issue #23 / BUG-03](https://github.com/artempanshyn/pythonstart/issues/23). Пошук знаходить тему за запитом із кратними пробілами; фільтр обробляє невалідний список прогресу.
- Пошкоджені записи прогресу перевіряються під час завантаження. Повторне виконання теми зберігає попередню кількість балів.

### Security

- Звичайний текст у каталозі, повідомленнях і віджеті виводиться через `textContent`.
- Скидання видаляє лише ключ прогресу PythonStart. Лінтер контролює заборонений шаблон виклику `eval()` у JavaScript.
