# Навчальний тренажер PythonStart

## 1. Загальна інформація

PythonStart - навчальний проєкт з освітнього компонента «Командна розробка програмних проєктів». Тренажер допоможе закріпити базові поняття Python через короткі пояснення та вправи.

## 2. Формат роботи та ролі

Виконавець проєкту - `artempanshyn`. Проєкт виконується індивідуально з поєднанням ролей технічного спеціаліста (Developer) і тестувальника (QA).

- Технічний спеціаліст відповідає за структуру проєкту, код і налаштування репозиторію.
- Тестувальник визначає сценарії перевірки, фіксує результати й перевіряє виправлення.

## 3. Освітня проблема та аудиторія

Під час перших занять з Python учням потрібно звикнути до синтаксису й навчитися читати результат виконання коду. Короткі вправи з поясненням відповіді допоможуть їм зосередитися на одній конструкції за раз. Основна аудиторія - учні 8–9 класів, які починають вивчати Python. Учитель може використовувати вправи для закріплення теми на уроці.

## 4. Мета та межі першої версії

Перший навчальний сценарій охоплює теми «Змінні», «Умови» та «Цикли». Учень обирає тему з каталогу, читає коротке пояснення, розбирає приклад коду й одразу отримує результат перевірки вправи. Реєстрацію, серверну базу даних та інтеграцію з електронним журналом відкладено.

## 5. Організація роботи

Завдання, зміни коду й результати перевірок фіксуються в репозиторії. Для кожного виправлення зберігаються умови перевірки та фактичний результат.

## 6. Структура проєкту та інструкція із запуску

- `src/main.py` - головний файл запуску тренажера.
- `src/math_quiz.py` - перевірка відповідей і підрахунок балів.
- `docs/` - методичні матеріали та документація проєкту.

Для запуску виконайте з кореня репозиторію:

```bash
python3 src/main.py
```
