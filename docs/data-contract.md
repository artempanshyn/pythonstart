# Контракт даних віджета PythonStart

`js/api.js` отримує й перевіряє JSON, а `js/apiWidget.js` відображає результат. Віджет працює після завантаження сторінки через HTTP або HTTPS.

## Джерела

| Запит | Використані поля відповіді |
| --- | --- |
| `GET ./data/daily-tips.json` | Масив `tips`. Поля `version` і `updatedAt` описують набір. |
| `GET https://api.github.com/repos/python/cpython` | `stargazers_count` → `stars`, `open_issues_count` → `openIssues`, `language`, `html_url` → `htmlUrl`. Запит публічний і не потребує токена. `open_issues_count` включає відкриті завдання й Pull Requests. |
| `GET ./data/non-existent-404.json` | Навмисний запит до відсутнього ресурсу для перевірки HTTP 404. |

Кожна порада містить непорожні рядки `id`, `category`, `title`, `explanation` і `codeSnippet`. Ідентифікатори унікальні. `codeSnippet` зберігає приклад Python зі вставленими переносами рядків. `stars` і `openIssues` мають бути цілими невід’ємними числами, `htmlUrl` - адресою офіційного репозиторію.

## Результат loadPythonTipData()

| Поле | Значення |
| --- | --- |
| `ok` | `true`, якщо поради отримано через HTTP; `false`, якщо підставлено вбудований набір. |
| `sourceLabel` | Бейдж для двох доступних джерел, локального JSON без статистики або автономних порад. |
| `tips` | Непорожній масив порад однакової структури для HTTP та резервного режиму. |
| `repoStats` | `{ stars, openIssues, language, htmlUrl }` з API або `null`. |
| `errorMessage` | Текст помилки основного запиту в резервному режимі або `null`. |

Звичайне завантаження запускає два запити паралельно. Модуль перевіряє `response.ok` перед читанням JSON і обмежує тривалість кожного запиту шістьма секундами. Якщо локальний JSON отримано, поради лишаються доступними при збої GitHub. Якщо основні поради недоступні через HTTP-помилку, розрив мережі чи некоректний JSON, віджет показує вбудовану пораду й кнопку повторного запиту. Режим без мережі стосується вже відкритої сторінки.
