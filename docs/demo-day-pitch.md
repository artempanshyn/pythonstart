## Готовність та план Б

- За 10 хвилин до виступу відкрити GitHub Pages у чистому профілі, перевірити проєктор, вивід зображення і масштаб. Переконатися, що прогрес починається з 0 балів.
- Тримати відкритою завантажену вкладку. За короткого збою мережі продовжити без перезавантаження, оскільки завантажена сторінка дозволяє перевіряти відповіді й зберігати прогрес.
- Якщо сторінку не вдається оновити, відкрити локальну копію тегу v1.0.0. У розпакованій папці виконати `python3 -m http.server 5500 --bind 127.0.0.1` і відкрити `http://127.0.0.1:5500/`. Локальний JSON надає поради, коли зовнішня статистика GitHub недоступна. У відкритому тренажері при відмові JSON діє вбудований набір.
- Якщо запуск у браузері затримує виступ, перейти до резервних слайдів 7-9. Показати пошук, діагностику, результат після оновлення, пораду та успішний CI. Зображення збережено під час перевірки.
- Увімкнути таймер з початку виступу. Після 3:20 повернутися до слайда 4, навіть якщо довелося перейти на резерв. Повну усну репетицію провести перед захистом.

## Запитання після показу

**Де зберігаються бали?** У `localStorage` браузера для цієї адреси. Після оновлення дані лишаються, а інший браузер починає з власного прогресу.

**Що було складним у перевірці?** Валідатор має розрізнити правильний результат, зайву оболонку `print()`, регістр та інші форми помилки. Тести покривають випадки, де легко переплутати неправильне оформлення з іншим значенням.

**Як підготувати спільний шкільний ПК?** На початку уроку відкрити окремий профіль або підтвердити «Скинути прогрес». Бали у браузері доповнюють спостереження вчителя, пояснення учня та перевірку роботи.

## Технічна репетиція

27.11.2026 перевірено маршрут живого демо в чистому профілі Chrome на GitHub Pages. Пошук показав одну картку, `print(15)` викликав діагностику, `15` принесло 10 балів, а після оновлення залишилася позначка «✓ Опрацьовано». Віджет отримав пораду та статистику GitHub. На локальній копії v1.0.0 із заблокованими зовнішніми запитами працювали вправи й порада з локального JSON. Це технічний прогін. Усна репетиція з таймером і публічний виступ заплановані окремо.
