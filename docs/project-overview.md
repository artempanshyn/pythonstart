# Методичний опис тренажера «PythonStart»

У цій папці зберігаються вимоги, навчальні сценарії та методичні матеріали PythonStart. Консольна вікторина допомагає учням пригадати, як у Python виводити текст і присвоювати значення змінній.

## Як пройти вікторину

У першому запитанні введіть назву функції без дужок, у другому - один символ присвоєння. Після кожної відповіді прочитайте повідомлення про результат. За дві правильні відповіді можна отримати 2 бали.
