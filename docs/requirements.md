# Специфікація вимог та межі MVP тренажера «PythonStart»

## 1. Опис освітньої проблеми

Під час самостійних вправ з Python учням 8-9 класів буває складно визначити, на якому кроці вони помилилися. За відсутності швидкого зворотного зв’язку вони можуть зупинитися після першої невдалої спроби.

**Потреба.** Учневі потрібні коротке пояснення українською, приклад коду та можливість одразу перевірити свій варіант відповіді.

**Рішення.** PythonStart об’єднує ці кроки у вебтренажері: учень обирає тему, читає приклад, виконує вправу й отримує відгук.

## 2. Цільова аудиторія

**Основний користувач.** Учень 8-9 класу, який тільки починає вивчати Python і тренується на уроці або вдома. Матеріал також підходить першокурснику, якому потрібно повторити основи.

**Додатковий користувач.** Учитель інформатики, який добирає тему для уроку, дає класу посилання та використовує результат для обговорення типових помилок.

## 5. Межі MVP v1.0 і план перевірки

- До MVP входять US-01 - US-07. Каталог містить чотири теми «Змінні», «Умови», «Цикли» та «Списки». Кожна тема має коротку теорію, приклад і щонайменше одну вправу. Перші три теми готуються на початкових етапах, «Списки» додаються до повного випуску.
- Базовий сценарій охоплює вибір теми, читання теорії, виконання вправ та перегляд результату. Застосунок працює у браузері. Відповіді порівнюються з підготовленими еталонами, а введений Python-код не виконується.
- Порожнє введення показує підказку й не змінює рахунок. Для тексту ігноруються крайні пробіли, а для Python-коду враховується регістр. Кожна вправа може додати щонайбільше один бал. Підсумок X з N і відсоток розраховуються за вправами обраної теми.
- У першому випуску відкладено локальне збереження прогресу між сеансами, відзнаки, перемикач оформлення, публічний рейтинг, реєстрацію, серверне сховище, ШІ-репетитора та інтеграцію з журналом.

**Гіпотеза.** Припускаємо, що учень 8-9 класу зможе самостійно відкрити тему, виконати вправу та пояснити причину помилки після прочитання відгуку.

**Перевірка.** Після готовності MVP запропонувати невеликій групі учнів виконати цей сценарій на комп’ютері або смартфоні. Зафіксувати, чи учень завершив його без підказки, де зупинився та чи зміг пояснити помилку. Окремо перевірити правильну, хибну та порожню відповідь, повторне натискання «Перевірити» і ширини 375 та 1280 px.

**Загальні критерії готовності.** Для завершення картки перевіряються її критерії, результати перевірки фіксуються в Issue, а зміна й документація узгоджуються з опублікованою версією. Незалежне рев’ю фіксується після того, як його дійсно проведено.
