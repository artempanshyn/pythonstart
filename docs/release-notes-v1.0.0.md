# Паспорт релізу PythonStart v1.0.0

Перший публічний випуск тренажера для учнів 8-9 класів. PythonStart пропонує чотири короткі уроки, вправи з підказками, збереження прогресу та поради з резервним джерелом.

[GitHub Pages](https://artempanshyn.github.io/pythonstart/) · [Інструкція для учнів і вчителів](user-guide.md) · [Журнал змін](../CHANGELOG.md)

## Вимоги та перевірки

| Історія з ЛР 4 | Реалізація | Перевірка |
| --- | --- | --- |
| US-01. Каталог | `data/topics.js`, `js/topics.js` | Тести каталогу, ST-03 |
| US-02. Теорія з прикладами | `data/topics.js`, `js/workspace.js` | Контракт даних, проходження чотирьох тем |
| US-03. Вправа | `js/workspace.js` | Проходження тем у браузері |
| US-04. Валідація | `js/validation.js` | Vitest, ST-04 |
| US-05. Пояснення помилки | `js/validation.js`, `js/messages.uk.js` | Тести діагностики, ST-04 |
| US-06. Підсумок | `js/storage.js`, `js/app.js` | Бали й кількість опрацьованих тем, ST-05. Окремий відсоток у підсумку не показується. |
| US-07. Інструкція | `docs/user-guide.md` | Перевірка посилання й роботи на 375 px |
